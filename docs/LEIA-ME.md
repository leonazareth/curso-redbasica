# Pasta `docs/`

Aqui ficam os arquivos do curso que os participantes baixam:
apresentações em PDF, manual, documentos auxiliares e — se forem
pequenos — os ZIPs dos exercícios.

## Regra de ouro: onde colocar cada arquivo

| Tamanho do arquivo | Onde colocar |
| --- | --- |
| até ~20 MB | nesta pasta `docs/` |
| acima de ~20 MB | em uma **Release** do GitHub (ver guia) |

O GitHub **recusa** qualquer arquivo acima de 100 MB e reclama acima de
50 MB. Além disso, tudo que entra no repositório fica lá para sempre,
mesmo que você apague depois — então ZIPs grandes de projeto QGIS é
melhor publicar como Release.

## Como o link fica

Um arquivo salvo como `docs/apresentacoes_curso.pdf` fica disponível em:

```
https://leonazareth.github.io/curso-redbasica/docs/apresentacoes_curso.pdf
```

(troque `curso-redbasica` pelo nome que você deu ao repositório)

Esse é o endereço que você cola no `js/main.js`.

## Nomes de arquivo

Sem acento, sem espaço, tudo minúsculo — espaço e acento quebram o link.

✅ `exercicio_dia01.zip`
❌ `Exercício dia 01.zip`

## Atenção

Este repositório é **público**. Não coloque aqui nada que não possa ser
visto por qualquer pessoa: propostas comerciais, contratos, dados de
clientes ou arquivos de projeto sigilosos.
